# Referências públicas verificadas — UX-01

A auditoria confirmou o escopo/edição corrente das referências públicas aplicáveis:

- ISO 6412-2:2017 — representação isométrica de tubulações;
- ISO 14617-1:2025 — regras gerais para símbolos gráficos em diagramas;
- ISO 10628-2:2012 — símbolos para diagramas químicos/petroquímicos;
- ANSI/ISA-5.1-2024 — símbolos e identificação de instrumentação/controle;
- API RP 574 — 5ª edição — práticas de inspeção de componentes de sistemas de tubulação;
- diagrams.net/draw.io — bibliotecas customizadas, connection points, custom shapes e templates como referência funcional/ergonômica.

**Importante:** páginas públicas confirmam escopo e vigência. A validação símbolo a símbolo não deve reproduzir conteúdo normativo protegido sem acesso/licença apropriados.
