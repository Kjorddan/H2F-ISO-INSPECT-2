# Guia de Homologação Corporativa Final — H2F

A homologação abaixo é humana e não pode ser substituída pelos gates automatizados.

## Checklist

- [ ] O pacote inicia por `INICIAR_H2F_ISO_INSPECT.bat` em Windows corporativo representativo.
- [ ] O editor carrega sem erro impeditivo.
- [ ] PipeRuns, componentes, branches e topologia são editáveis e coerentes.
- [ ] `.h2fiso` salva e reabre preservando o documento.
- [ ] O PDF exportado abre corretamente.
- [ ] Uma fotografia/imagem industrial real autorizada é analisada localmente.
- [ ] Linhas, texto e símbolos são apresentados com confidence/provenance coerentes.
- [ ] Baixa confiança exige decisão humana.
- [ ] A reconstrução produz entidades nativas editáveis.
- [ ] O modo de comparação com a referência original é utilizável.
- [ ] Não há “invenção” de texto ilegível como dado confiável.
- [ ] Não há problema visual impeditivo em resolução corporativa típica.
- [ ] O comportamento geral é aceitável para uso operacional H2F.
